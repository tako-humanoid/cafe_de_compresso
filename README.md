# cafe-de-compresso
スマホで撮った写真をリサイズして他サービスに共有できるアプリです
=======
## What is this?

スマホで撮影した写真など、重たいデータ(6-20MB)くらいを用途に応じてリサイズ・圧縮し他のサービスに共有するアプリです。

## How to use

一番上の" Select your best pic! " をタップしてください。ファイル選択画面が出ます。1つ画像データを選択してください。

次に真ん中の Short, Tall, Grande のどれかを選んでください
Short はだいたい 256kb以下, Tallは　512kB以下, Grandeは 1024kB以下に圧縮します。

スマホのギガを節約したかったので作成しました。これがきっかけでGodotのプラグインの作り方を知ることになりました。こっちのほうが大変でした。
